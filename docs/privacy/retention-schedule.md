# Retention schedule

| Data | Retention | Basis |
|------|-----------|-------|
| Account / profile | Until deletion request + grace | Contract |
| Identity fields + scan + signature | 30 days after card1 Completed; hard cap 90 days after upload | Consent + minimisation |
| Proofs | Delete after approve/reject + 30 days | Legitimate interest support |
| Payments / invoices | Statutory tax retention (anonymise PII on erasure) | Legal obligation |
| Link clicks | 24 months | Legitimate interest / partner proof |
| Accommodation leads | 24 months after closed | Contract/support |
| Audit log | 36 months | Security |
| Consents | Duration of processing + 3 years | Accountability |
| Sessions | 14 days idle max / absolute 30 days | Security |
| Cookie consent choice | 6–12 months then re-ask | TDDDG |
