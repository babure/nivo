# NIVO PRD (Phase 1)

## Problem

International students moving to Germany need a clear path for blocked account, SIM, accommodation and later insurance/jobs. NIVO refers them to partners and supports setup for a one-time €149 fee.

## Goals

1. Student registers, verifies, pays, completes identity, uses 4-card dashboard.
2. Admin has granular permissions, approvals, and publish workflows.
3. Consultancies track referrals without seeing sensitive identity data.
4. GDPR/TDDDG-compliant: encryption, consents, retention, deletion.

## Non-goals (Phase 1)

- Insurance cards live (structure only)
- Partner API auto-complete (stubs for A/B)
- German language content
- WhatsApp notifications
- Consultancy commission payouts

## Success metrics

- Brief acceptance tests 1–10 pass on mobile + desktop
- ≥80% of paying students complete identity in one session
- Zero high/critical pen-test findings open at launch
- Consultancy RLS isolation proven by automated tests

## Phases

- Phase 1: Launch modules M0–M12
- Phase 2: Insurance, partner automation, vouchers, commissions
- Phase 3: Job References live, German locale
