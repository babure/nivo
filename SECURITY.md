# Security

## Reporting

Email security issues to the NIVO operators (placeholder: security@nivo.example). Do not open public issues for vulnerabilities.

## Practices

- No secrets in the repository
- Dependency and secret scanning in CI
- ASVS Level 2 checklist before launch (`docs/security/asvs-checklist.md`)
- External penetration test required for production go-live
- PII redacted from logs; identity data encrypted at rest
